Label rendering samples

Open this page after npm run build: it renders the samples below through the bundled labelizer.

  • Unicode letters: Aérodynamique, λ, Δp_c, y_aéro
  • Spaces in node names: MDA Gauss-Seidel, Discipline 1, Opt. disciplinaires
  • LaTeX subset: x^{(0)}, x_shared^(0), \hat{y}_2
  • Already supported: y_12^*, &#955;, and the process numbering prefix on Optimizer
